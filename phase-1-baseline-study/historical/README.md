# Historical Phase 1 wrappers

These scripts preserve the intent of uploaded local convenience/analysis files. Machine-specific paths were replaced with repository-relative placeholders to prevent leaking workstation details. Exact uploaded bytes remain recoverable from commit `06a9c193d85b655bb82a9224bbd1086777dd9755` and are checksummed in `docs/original-file-manifest.sha256`.

Use `src/lce/` and the documented CLI as the active implementation.
