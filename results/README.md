# Compact result summaries

These CSVs are deterministic aggregates of committed raw result files and are regenerated by `python3 scripts/build_portfolio_assets.py`.

- `gnn-performance-by-sample-size.csv` — one row per N/model over all 14 rules.
- `gnn-performance-by-rule-family.csv` — one row per rule family/model over N=500/1,000/2,000.
- `node-importance-by-sample-size.csv` — one row per N/node with coverage counts.
- `result-catalog.csv` — structural inventory of the uploaded result files.

See `reports/result-provenance.md` before interpreting these descriptive aggregates.
